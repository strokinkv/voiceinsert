# VoiceInsert

![VoiceInsert](docs/assets/VoiceInsert.png)

VoiceInsert - фоновая утилита для Windows 11. Она записывает речь с микрофона, отправляет WAV-аудио в OpenAI-совместимый Audio API и вставляет полученный текст в активное окно через буфер обмена. Также поддерживается перевод речи в английский текст, если выбранная модель и API endpoint это позволяют.

Документация на английском: [README.md](README.md)

Техническое задание: [docs/technical-specification.md](docs/technical-specification.md)

## Установка

Для установки скачайте и запустите VoiceInsertSetup.exe.

Тихая установка:

```powershell
.\artifacts\installer\VoiceInsertSetup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

## Как пользоваться

1. Запусти VoiceInsert. Приложение появится в системном трее.
2. Открой `Settings` из контекстного меню в трее.
3. Выбери API-профиль, укажи API-ключ при необходимости, загрузи модели и выбери модель.
4. Выбери микрофон и при необходимости проверь входной уровень.
5. Поставь курсор в нужное окно и нажми `Ctrl+Space` для распознавания речи.
6. Для перевода речи на английский используй `Alt+Y`.

Во время записи появляется компактное окно с бегущей амплитудой сигнала. После получения ответа API текст вставляется в активное окно через буфер обмена.

## API-профили по умолчанию

При первом запуске VoiceInsert создает два API-профиля:

- `wlast`, первый и основной профиль: `http://127.0.0.1:9573`
- `groq`: `https://api.groq.com/openai/`, без API-ключа

Загрузка моделей:

```text
GET {base_url}/v1/models
```

Транскрибация:

```text
POST {base_url}/v1/audio/transcriptions
```

Перевод речи на английский:

```text
POST {base_url}/v1/audio/translations
```

В каждом API-профиле есть одно поле модели. Одна и та же выбранная модель используется для транскрибации и перевода. Если запрос перевода завершается ошибкой, VoiceInsert пишет в лог выбранную модель и подсказку, что модель может не поддерживать audio translation.

Обычная транскрибация не переводит текст на стороне VoiceInsert. Если endpoint-адрес транскрибации возвращает перевод, это поведение API, модели или параметров `language`.

## Текущее поведение

- Контекстное меню в трее локализуется и содержит `Settings` / `Exit`.
- Горячая клавиша транскрибации по умолчанию: `Ctrl+Space`.
- Горячая клавиша перевода на английский по умолчанию: `Alt+Y`.
- Режимы записи: переключатель, удержание, до тишины.
- В режимах переключателя и удержания тишина не останавливает запись; действует только максимальная длительность записи.
- Вставка текста выполняется через буфер обмена.
- API-ключ защищается Windows DPAPI отдельно для каждого профиля.
- Аудио и распознанный текст не сохраняются на диск.
- Логи не содержат аудио, распознанный текст и API-ключ.
- Окно настроек использует верхнюю навигацию, подсказки на конкретных полях, компактное управление профилями, одно поле модели и общую строку состояния.
- Выбор микрофона показывает полные имена устройств Windows CoreAudio, а полное выбранное имя доступно во всплывающей подсказке.
- Раздел `Логи` показывает время и текст последней ошибки с момента запуска приложения.

## Приватность

- VoiceInsert не сохраняет аудио на диск.
- Распознанный текст не сохраняется после вставки.
- В логи не записываются аудио, распознанный текст и API-ключи.
- API-ключи хранятся через Windows DPAPI отдельно для каждого профиля.
- Аудио отправляется только в API endpoint-адрес, который указан в выбранном профиле.
- При использовании профиля `wlast` по умолчанию запросы идут на локальный адрес `http://127.0.0.1:9573`.

## Ограничения

- Поддерживается только Windows 11.
- Нужен OpenAI-совместимый Audio API с endpoint-ами `/v1/audio/transcriptions`, `/v1/audio/translations` и `/v1/models`.
- Перевод речи на английский зависит от того, поддерживает ли выбранная модель endpoint переводов.
- Вставка выполняется через буфер обмена, поэтому поведение может зависеть от активного приложения.
- Полные имена микрофонов берутся через Windows CoreAudio, а запись выполняется через WinMM/NAudio.
