# VoiceInsert

![VoiceInsert](docs/assets/VoiceInsert.png)

VoiceInsert - фоновая утилита для Windows 11. Она записывает речь с микрофона, отправляет WAV-аудио в OpenAI-совместимый Audio API и вставляет полученный текст в активное окно через буфер обмена.

Документация на английском: [README.md](README.md)

Техническое задание: [docs/technical-specification.md](docs/technical-specification.md)

## Установка

Для установки скачайте и запустите VoiceInsertSetup.exe.

Тихая установка:

```powershell
.\artifacts\installer\VoiceInsertSetup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

## Разработка

VoiceInsert переписывается как Windows-приложение на Rust с UI на Slint.

```powershell
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
cargo build --release
.\scripts\package.ps1
```

## Как пользоваться

1. Запусти VoiceInsert. Приложение появится в системном трее.
2. Открой `Settings` из контекстного меню в трее.
3. Выбери API-профиль, укажи API-ключ при необходимости, загрузи модели и выбери модель.
4. Поставь курсор в нужное окно и нажми `Ctrl+Space` для распознавания речи.

Во время записи появляется компактное floating-окно со статусом по центру и бегущей амплитудой сигнала. После получения ответа API текст вставляется в активное окно через буфер обмена.

## API-профили по умолчанию

При первом запуске VoiceInsert создает два API-профиля:

- `ai2npu`, первый и основной профиль: `http://localhost:9555`
- `groq`: `https://api.groq.com/openai/`, без API-ключа

Загрузка моделей:

```text
GET {base_url}/v1/models
```

Транскрибация:

```text
POST {base_url}/v1/audio/transcriptions
```

В каждом API-профиле есть одно поле модели. VoiceInsert отправляет аудио только в endpoint транскрибации.

## Текущее поведение

- Контекстное меню в трее локализуется и содержит `Settings` / `Exit`.
- Горячая клавиша транскрибации по умолчанию: `Ctrl+Space`.
- Режимы записи: переключатель, удержание, до тишины.
- В режимах переключателя и удержания тишина не останавливает запись; действует только максимальная длительность записи.
- Floating-окно записи показывает только компактный waveform без отдельных подписей `live` или `silent`.
- Вставка текста выполняется через буфер обмена.
- API-ключ защищается Windows DPAPI отдельно для каждого профиля.
- Аудио и распознанный текст не сохраняются на диск.
- Логи не содержат аудио, распознанный текст и API-ключ.
- Окно настроек использует одноэкранную карточную компоновку без вкладок и прокрутки. Язык ввода API не показывается; аудиозапросы по умолчанию используют русский (`ru`) как язык ввода.
- VoiceInsert всегда записывает с микрофона, выбранного в системе по умолчанию.
- Раздел `Логи` показывает папку логов, log level и последнюю ошибку с момента запуска приложения.

## Приватность

- VoiceInsert не сохраняет аудио на диск.
- Распознанный текст не сохраняется после вставки.
- В логи не записываются аудио, распознанный текст и API-ключи.
- API-ключи хранятся через Windows DPAPI отдельно для каждого профиля.
- Аудио отправляется только в API endpoint-адрес, который указан в выбранном профиле.
- При использовании профиля `ai2npu` по умолчанию запросы идут на локальный адрес `http://localhost:9555`.

## Диагностика проблем

- **Текст не вставляется:** проверьте, что целевое приложение в фокусе, увеличьте задержку перед вставкой в `Settings > Вставка` и попробуйте отключить восстановление буфера обмена для приложений с нестандартной обработкой clipboard.
- **Горячая клавиша не работает:** выберите комбинацию минимум с одним модификатором и избегайте сочетаний, занятых активным приложением. `Ctrl+Space` может конфликтовать с IDE и методами ввода.
- **Микрофон не найден или уровень нулевой:** проверьте системное устройство ввода Windows и разрешения доступа к микрофону.
- **API возвращает 401:** проверьте API-ключ активного профиля. Ключи хранятся отдельно для каждого профиля.
- **API возвращает 404 или 422:** убедитесь, что Base URL не содержит `/v1/audio/...`, а сервер поддерживает OpenAI-совместимые endpoint-ы `/v1/models` и `/v1/audio/transcriptions`.
- **Установщик не может закрыть приложение:** выйдите из VoiceInsert через меню в трее перед установкой или удалением.

## Ограничения

- Поддерживается только Windows 11.
- Нужен OpenAI-совместимый Audio API с endpoint-ами `/v1/audio/transcriptions` и `/v1/models`.
- Вставка выполняется через буфер обмена, поэтому поведение может зависеть от активного приложения.
- Ввод с микрофона записывается через Rust audio backend и перед отправкой в API приводится к mono 16 kHz PCM WAV.
