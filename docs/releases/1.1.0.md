# VoiceInsert 1.1.0

VoiceInsert 1.1.0 focuses on reliability, diagnostics, test coverage, and release automation.

## Highlights

- Fixed recording lifecycle races so an old max-duration timer cannot stop a newer recording.
- Prevented duplicate app instances from continuing startup.
- Added API base URL validation and a dedicated API profile health check.
- Improved hotkey validation and normalization.
- Restores the full previous clipboard data object instead of only plain text.
- Expanded automated tests from 17 to 45 tests.
- Added coverage collection, dependency audit, formatting checks, and a release workflow.

## Reliability

- Recording sessions now have their own session id.
- Max-duration timeout is cancelled when a recording stops normally.
- Starting a new recording is ignored while a previous transcription/insertion operation is still active.
- Startup failures now clean up partially initialized recording state.

## API and Settings

- `TranscriptionClient` and `ModelsClient` now set authorization headers per request.
- Invalid API base URLs now produce clear errors.
- The `Test connection` button now uses an API profile health check instead of only reloading models.

## Hotkeys

- Hotkeys are normalized into a stable modifier order.
- Shortcuts without modifiers are rejected.
- Unknown keys are rejected.
- Duplicate transcription and translation hotkeys are de-conflicted.

## Clipboard

- Clipboard restore now preserves the whole `IDataObject` where possible, improving compatibility with rich text, HTML, images, and file clipboard payloads.

## CI/CD

- CI now builds with warnings as errors.
- CI verifies formatting with `dotnet format`.
- CI runs NuGet vulnerability audit.
- CI collects coverage using `coverlet.collector`.
- A release workflow packages `VoiceInsertSetup.exe` and uploads it to GitHub Releases for semantic version tags such as `1.1.0`.

## Upgrade notes

- Existing settings are normalized on startup.
- Invalid hotkeys may be reset to safe defaults.
- API keys remain protected by Windows DPAPI and are not migrated to plaintext.

## Verification

Validated locally with:

- `dotnet build VoiceInsert.slnx --configuration Release -warnaserror`
- `dotnet test VoiceInsert.slnx --configuration Release`
- `dotnet format VoiceInsert.slnx --verify-no-changes --no-restore`
- `dotnet list VoiceInsert.slnx package --vulnerable --include-transitive`
