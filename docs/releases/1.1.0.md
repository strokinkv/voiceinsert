# VoiceInsert 1.1.0

VoiceInsert 1.1.0 — релиз про надежность записи, диагностику API, расширенное тестирование и автоматизацию публикации.

## Главное

- Исправлены гонки жизненного цикла записи: старый таймер максимальной длительности больше не может остановить новую запись.
- Добавлена защита от запуска второго экземпляра приложения.
- Добавлена валидация Base URL и отдельная проверка API-профиля.
- Улучшена нормализация и проверка горячих клавиш.
- Восстановление буфера обмена теперь сохраняет весь предыдущий `IDataObject`, а не только plain text.
- Количество автоматических тестов увеличено с 17 до 45.
- Добавлены coverage, dependency audit, проверка форматирования и release workflow.

## Надежность записи

- Каждая запись теперь имеет свой session id.
- Таймер максимальной длительности отменяется при штатной остановке записи.
- Новый старт записи игнорируется, пока предыдущая операция еще транскрибируется или вставляет текст.
- При ошибке старта записи приложение очищает частично созданное состояние recorder-а.

## API и настройки

- `TranscriptionClient` и `ModelsClient` больше не меняют общий `HttpClient.DefaultRequestHeaders`; авторизация задается на каждый запрос отдельно.
- Невалидные API Base URL теперь дают понятные ошибки.
- Кнопка `Проверить` в настройках API теперь использует health-check профиля, а не просто повторную загрузку моделей.
- Health-check проверяет доступность `/v1/models`, наличие моделей и наличие выбранной модели в ответе API.

## Горячие клавиши

- Горячие клавиши нормализуются в стабильном порядке модификаторов.
- Комбинации без модификаторов отклоняются.
- Неизвестные клавиши отклоняются.
- Одинаковые горячие клавиши для транскрибации и перевода автоматически разводятся на безопасные значения.

## Буфер обмена

- Восстановление clipboard теперь по возможности сохраняет весь `IDataObject`.
- Это улучшает совместимость с rich text, HTML, изображениями и файловыми payload-ами в буфере обмена.

## CI/CD

- CI собирает проект с `-warnaserror`.
- CI проверяет форматирование через `dotnet format`.
- CI запускает NuGet vulnerability audit.
- CI собирает coverage через `coverlet.collector`.
- Добавлен release workflow: по тегу вида `1.1.0` собирается `VoiceInsertSetup.exe` и прикладывается к GitHub Release.

## Обновление

- Существующие настройки нормализуются при запуске.
- Невалидные горячие клавиши могут быть сброшены на безопасные значения.
- API-ключи остаются защищены Windows DPAPI и не переносятся в открытый текст.

## Проверка

Перед публикацией локально проверено:

- `dotnet build VoiceInsert.slnx --configuration Release -warnaserror`
- `dotnet test VoiceInsert.slnx --configuration Release`
- `dotnet format VoiceInsert.slnx --verify-no-changes --no-restore`
- `dotnet list VoiceInsert.slnx package --vulnerable --include-transitive`

## English summary

VoiceInsert 1.1.0 improves recording reliability, API diagnostics, hotkey validation, clipboard restoration, automated tests, and release automation.

Highlights:

- Fixed recording lifecycle race conditions.
- Added single-instance startup protection.
- Added API profile health checks and Base URL validation.
- Improved hotkey validation and normalization.
- Restores the full previous clipboard data object where possible.
- Expanded automated tests from 17 to 45.
- Added coverage, dependency audit, formatting checks, and GitHub release workflow.
