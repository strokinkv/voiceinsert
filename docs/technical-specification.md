# VoiceInsert: техническое задание

## 1. Назначение

VoiceInsert - фоновая Windows 11 утилита на Rust. Приложение записывает речь с микрофона по глобальной горячей клавише, отправляет WAV-аудио в OpenAI-совместимый audio API и вставляет полученный текст в активное окно через буфер обмена.

Приложение работает из системного трея. Основное окно - компактные настройки.

## 2. Платформа

- ОС: Windows 11.
- Язык: Rust.
- UI: Slint.
- Tray icon: Windows tray integration.
- Установка: Inno Setup installer.
- Директория установки: `%APPDATA%\VoiceInsert`.
- Исполняемый файл: `VoiceInsert.exe`.
- Установщик: `VoiceInsertSetup.exe`.

## 3. Основной сценарий

1. Пользователь запускает VoiceInsert.
2. Приложение появляется в системном трее.
3. Пользователь ставит курсор в нужное поле ввода.
4. Пользователь нажимает горячую клавишу записи.
5. Приложение проигрывает звук начала записи.
6. Появляется компактное floating-окно с waveform и статусом.
7. Аудио пишется в WAV в памяти.
8. Запись завершается по режиму записи или по максимальной длительности.
9. Приложение проигрывает звук остановки записи.
10. WAV-аудио отправляется в настроенный API.
11. Полученный текст вставляется в активное окно через буфер обмена.
12. Floating-окно скрывается.

Аудио и текст не сохраняются на диск.

## 4. Горячие клавиши и режимы записи

Горячие клавиши глобальные и работают, когда приложение находится в фоне.

- Транскрибация по умолчанию: `Ctrl+Space`.
- Перевод речи на английский по умолчанию: `Alt+Y`.

Режимы записи:

- `Toggle`: первое нажатие начинает запись, второе завершает.
- `Hold`: запись идет, пока пользователь удерживает горячую клавишу.
- `Silence timeout`: запись завершается после обнаружения тишины заданной длительности.

Silence timeout применяется только в режиме `Silence timeout`. В режимах `Toggle` и `Hold` запись не останавливается по тишине; действует только ограничение максимальной длительности записи.

Пользователь может менять обе горячие клавиши через захват комбинации в настройках.

## 5. Вставка текста

Вставка выполняется только через буфер обмена:

- приложение помещает полученный текст в clipboard;
- эмулирует `Ctrl+V` в активном окне;
- опционально восстанавливает предыдущий clipboard;
- позволяет настроить задержку перед вставкой и задержку перед восстановлением clipboard.

Надежность вставки важнее восстановления старого содержимого буфера обмена.

## 6. API-профили

Настройки API сгруппированы в профили. Каждый профиль хранит:

- имя профиля;
- Base URL;
- API key;
- Model;
- Language;
- Temperature;
- Request timeout.

API key хранится отдельно для каждого профиля через Windows DPAPI.

Профили по умолчанию:

- `ai2npu`: первый и основной профиль, `http://localhost:9555`, модель `openai/whisper-large-v3-turbo`;
- `groq`: `https://api.groq.com/openai/`, без API key, модель `whisper-large-v3`.

В GUI есть одно поле модели. Эта модель используется и для транскрибации, и для перевода речи. Если выбранная модель не поддерживает перевод, ошибка фиксируется в логах.

Prompt-поля не отображаются пользователю в GUI.

## 7. API endpoints

Загрузка моделей:

```text
GET {base_url}/v1/models
```

Транскрибация:

```text
POST {base_url}/v1/audio/transcriptions
```

Перевод речи на английский:

```text
POST {base_url}/v1/audio/translations
```

Запросы отправляются как `multipart/form-data`.

Поля запроса транскрибации:

- `file`: WAV-аудио;
- `model`: выбранная модель;
- `language`: если задан;
- `response_format`: `json`;
- `temperature`: если задан.

Поля запроса перевода:

- `file`: WAV-аудио;
- `model`: выбранная модель;
- `response_format`: `json`;
- `temperature`: если задан.

Ожидаемый успешный ответ:

```json
{
  "text": "recognized text"
}
```

При ошибке перевода приложение логирует выбранную модель и диагностическое сообщение, что модель может не поддерживать audio translation.

## 8. Аудио

- Формат отправляемого аудио: WAV, mono, 16 kHz, signed 16-bit little-endian PCM.
- Аудио с устройства ввода приводится к mono и ресемплится в 16 kHz перед отправкой.
- WAV-параметры не доступны пользователю.
- Для записи всегда используется системное устройство ввода Windows по умолчанию.
- Выбор микрофона в GUI отсутствует.
- Аудио хранится в памяти.
- Временные аудиофайлы не создаются.
- После операции аудиобуфер очищается.
- Должна быть защита от слишком длинной записи по времени и размеру буфера.
- В настройках не отображается отдельный раздел аудио.

## 9. Floating-окно

При записи отображается компактное полупрозрачное окно поверх остальных окон, без системного заголовка и кнопки закрытия. Окно располагается рядом с областью системных часов, слева и выше панели задач.

Окно показывает:

- бегущую waveform-амплитуду во времени;
- пунктирную линию при тишине;
- столбики/заливку по амплитуде при голосе;
- статус `Recording`, `Transcribing` или `Inserting`.

Верхняя и нижняя части waveform и заливка между ними используют один цвет. График каждой новой записи начинается заново и не должен зависать на максимуме после громкого звука.

Windows toast-уведомления не используются.

## 10. Звуки

Приложение проигрывает короткие встроенные звуки:

- начало записи;
- остановка записи;
- ошибка.

В разделе `Звуки` можно включить/выключить звуки и протестировать start/stop/error sound.

## 11. Окно настроек

Окно настроек компактное, с современной светлой темой, `Segoe UI Variable Text` с fallback на `Segoe UI`, sidebar-навигацией слева и общей строкой состояния внизу.

Требования к UI:

- разделы расположены в левой sidebar-навигации;
- у каждого пункта навигации есть tooltip;
- у конкретных настроек внутри вкладок есть field-level tooltip с пояснением назначения поля;
- tooltip должен переносить текст по словам и не обрезать длинные строки;
- внутри выбранного раздела нет дублирующего заголовка;
- строка состояния находится слева от кнопки сохранения;
- размер окна статический и рассчитан по самой крупной вкладке;
- выпадающие списки не должны обрезать текст;
- элементы внутри вкладок не должны наезжать друг на друга.

Разделы:

- `Общие`: автозапуск, язык, фиксированное поведение запуска в tray и окна записи.
- `Горячие клавиши`: текущие комбинации, захват новых комбинаций, режим записи, параметры тишины, максимальная длительность.
- `API Profile`: профиль API, Base URL, API key, Model, Language, Temperature, Timeout, загрузка моделей, проверка соединения.
- `Вставка`: clipboard insertion, восстановление clipboard, задержки.
- `Звуки`: включение звуков и тестовые кнопки.
- `Логи`: папка логов, log level, последняя ошибка за текущий запуск, открытие папки логов, очистка логов.

В разделе API имя профиля, выбор профиля, добавление и удаление профиля объединены в одну строку. Добавление и удаление выполняются компактными графическими кнопками `+` и `-`.

## 12. Tray icon

Контекстное меню tray icon содержит только:

- `Settings`;
- `Exit`.

Меню локализуется согласно выбранному языку интерфейса.

Иконка имеет состояния:

- idle;
- recording;
- transcribing;
- error, кратковременно.

## 13. Автозапуск

Автозапуск включается только через галочку в GUI.

Registry key:

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
```

Интерактивный установщик может предложить запустить приложение после установки, но не включает автозапуск сам.

## 14. Установка и удаление

Installer requirements:

- установка в `%APPDATA%\VoiceInsert`;
- имя приложения в winget/ARP: `VoiceInsert`;
- package id: `strokinkv.VoiceInsert`;
- создание Start Menu shortcut;
- интерактивная галочка запуска приложения после установки;
- тихая установка:

```powershell
VoiceInsertSetup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

- регистрация тихого удаления для `winget uninstall "VoiceInsert" --silent`;
- корректное обновление поверх предыдущей версии.

## 15. Настройки и секреты

Обычные настройки хранятся в:

```text
%APPDATA%\VoiceInsert\settings.json
```

API key нельзя хранить открытым текстом. Используется Windows DPAPI.

DPAPI - встроенный механизм Windows Data Protection API. Он шифрует секреты так, чтобы расшифровать их мог тот же Windows-пользователь на той же машине. Приложению не нужен отдельный мастер-пароль или собственное хранение ключей.

## 16. Логи и приватность

Логи пишутся в:

```text
%LOCALAPPDATA%\VoiceInsert\Logs
```

В логи нельзя писать:

- распознанный текст;
- аудио;
- API key;
- полный request body;
- полный response body, если он может содержать пользовательский текст.

Можно писать:

- время события;
- состояние приложения;
- длительность записи;
- размер аудио;
- endpoint/base URL без секретов;
- HTTP status code;
- тип ошибки;
- stack trace;
- длительность API-запроса;
- факт успешной вставки без текста.

Раздел `Логи` показывает дату и текст последней ошибки с момента запуска приложения.

Приложение само отправляет данные только в endpoint, настроенный пользователем. При использовании `ai2npu` по умолчанию данные уходят на локальный API.

## 17. Локализация

GUI поддерживает:

- Русский;
- English.

Выбранный язык сохраняется и применяется к настройкам и tray menu.

## 18. Обработка ошибок

При ошибке приложение должно:

- проиграть error sound;
- закрыть floating-окно, если оно активно;
- записать технические детали в лог без пользовательского текста;
- обновить последнюю ошибку в разделе `Логи`;
- не вставлять неполный или ошибочный текст;
- вернуться в idle state.

Типовые ошибки:

- микрофон недоступен или занят;
- горячая клавиша не зарегистрирована;
- API key пустой для API, где он нужен;
- Base URL некорректный;
- API недоступен;
- timeout;
- HTTP error;
- модель не поддерживает translation endpoint;
- ответ API не содержит `text`;
- clipboard недоступен;
- вставка не удалась.

## 19. Acceptance criteria

1. Приложение устанавливается на Windows 11 в `%APPDATA%\VoiceInsert`.
2. После запуска появляется tray icon.
3. Tray menu содержит `Settings` и `Exit` и локализуется.
4. Настройки открываются из tray menu.
5. По умолчанию создаются профили `ai2npu` и `groq`.
6. `ai2npu` является первым активным профилем.
7. `ai2npu` указывает на `http://localhost:9555` и использует модель `openai/whisper-large-v3-turbo`.
8. `groq` указывает на `https://api.groq.com/openai/`, создается без API key и использует `whisper-large-v3`.
9. Можно создать, выбрать и удалить API-профиль.
10. Загрузка моделей выполняется через `GET {base_url}/v1/models` выбранного профиля.
11. В GUI есть одно поле `Model`.
12. Транскрибация вызывает `POST {base_url}/v1/audio/transcriptions`.
13. Перевод вызывает `POST {base_url}/v1/audio/translations`.
14. Если перевод не поддерживается моделью, ошибка видна в логах.
15. `Ctrl+Space` запускает транскрибацию.
16. `Alt+Y` запускает перевод речи на английский.
17. Работают режимы `Toggle`, `Hold` и `Silence timeout`.
18. В `Toggle` и `Hold` тишина не останавливает запись.
19. Во время записи показывается floating waveform window.
20. Текст вставляется через clipboard в активное окно.
21. Аудио и распознанный текст не сохраняются на диск.
22. Логи не содержат аудио, распознанный текст и API key.
23. Раздел `Логи` показывает папку логов, log level и последнюю ошибку текущего запуска.
24. API key хранится через DPAPI отдельно для каждого профиля.
25. Установщик поддерживает тихую установку и тихое удаление.
26. В настройках есть tooltip для разделов и основных полей внутри вкладок.
27. VoiceInsert всегда использует системный микрофон по умолчанию.
