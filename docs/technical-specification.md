# VoiceInsert: техническое задание

## 1. Назначение

VoiceInsert - фоновая Windows 11 утилита на Rust. Приложение записывает речь с системного микрофона по глобальной горячей клавише, отправляет WAV-аудио в OpenAI-совместимый Audio API и вставляет полученный текст в активное окно через буфер обмена.

Приложение работает из системного трея. Основной пользовательский интерфейс - одноэкранное окно настроек.

## 2. Платформа

- ОС: Windows 11.
- Язык: Rust.
- UI: Slint.
- Tray icon: Windows tray integration.
- Установка: Inno Setup installer.
- Директория установки: `%APPDATA%\VoiceInsert`.
- Исполняемый файл: `VoiceInsert.exe`.
- Установщик: `VoiceInsertSetup.exe`.

## 3. Основной сценарий

1. Пользователь запускает VoiceInsert.
2. Приложение появляется в системном трее.
3. Пользователь ставит курсор в нужное поле ввода.
4. Пользователь нажимает горячую клавишу записи.
5. Приложение проигрывает звук начала записи, если включено звуковое оповещение.
6. По краям экрана появляется зелёная рамка-индикатор записи.
7. Аудио пишется в WAV в памяти.
8. Запись завершается по режиму записи, по тишине или по максимальной длительности.
9. Приложение проигрывает звук остановки записи, если включено звуковое оповещение.
10. Рамка-индикатор становится оранжевой на время распознавания и вставки.
11. WAV-аудио отправляется в настроенный API.
12. Полученный текст вставляется в активное окно через буфер обмена.
13. Индикатор скрывается, приложение возвращается в idle state.

Аудио и распознанный текст не сохраняются на диск.

## 4. Горячие клавиши и режимы записи

Горячие клавиши глобальные и работают, когда приложение находится в фоне.

- Горячая клавиша транскрибации по умолчанию: `Ctrl+Space`.
- Сценарий перевода удалён; отдельной горячей клавиши перевода нет.
- Поддерживается захват одиночных клавиш и сочетаний.
- Для клавиши Windows Copilot используется F23.

Режимы записи:

- `Toggle` / `Переключатель`: первое нажатие начинает запись, второе завершает запись и запускает транскрибацию.
- `Hold` / `Удержание`: запись идёт, пока пользователь удерживает горячую клавишу.
- `Hybrid` / `Гибрид`: короткое нажатие работает как `Toggle`; если горячая клавиша удерживалась дольше 2 секунд, отпускание завершает запись как в `Hold`; длинная пауза завершает запись по параметрам режима тишины.
- `SilenceTimeout` / `Тишина`: запись завершается после обнаружения тишины заданной длительности.

В режиме ожидания ответа API повторное нажатие горячей клавиши отменяет активную транскрибацию и возвращает приложение в idle state.

## 5. Вставка текста

Вставка выполняется только через буфер обмена:

- приложение помещает полученный текст в clipboard;
- эмулирует `Ctrl+V` в активном окне;
- опционально восстанавливает предыдущий clipboard;
- позволяет настроить задержку перед вставкой и задержку перед восстановлением clipboard.

Надёжность вставки важнее восстановления старого содержимого буфера обмена.

## 6. API профили

Настройки API сгруппированы в профили. Каждый профиль хранит:

- имя профиля;
- Base URL;
- API key;
- Model;
- Language;
- Temperature;
- Request timeout.

API key хранится отдельно для каждого профиля через Windows DPAPI.

Профили по умолчанию:

- `ai2npu`: первый и основной профиль, `http://localhost:9555`, модель `openai/whisper-large-v3-turbo`;
- `groq`: `https://api.groq.com/openai/`, без API key, модель `whisper-large-v3`.

В GUI есть выпадающий список API профилей и выпадающий список моделей. Список моделей загружается автоматически при запуске приложения, переключении активного профиля и сохранении профиля.

Prompt-поля не отображаются пользователю в GUI.

## 7. API endpoints

Загрузка моделей:

```text
GET {base_url}/v1/models
```

Транскрибация:

```text
POST {base_url}/v1/audio/transcriptions
```

Запросы отправляются как `multipart/form-data`.

Поля запроса транскрибации:

- `file`: WAV-аудио;
- `model`: выбранная модель;
- `language`: если задан;
- `response_format`: `json`;
- `temperature`: если задан.

Ожидаемый успешный ответ:

```json
{
  "text": "recognized text"
}
```

API метод `translate` не используется. Сценарий перевода русского текста на английский отсутствует.

## 8. Аудио

- Формат отправляемого аудио: WAV, mono, 16 kHz, signed 16-bit little-endian PCM.
- Аудио с устройства ввода приводится к mono и ресемплится в 16 kHz перед отправкой.
- WAV-параметры не доступны пользователю.
- Для записи всегда используется системное устройство ввода Windows по умолчанию.
- Выбор микрофона в GUI отсутствует.
- Аудио хранится в памяти.
- Временные аудиофайлы не создаются.
- После операции аудиобуфер очищается.
- Слишком короткая, пустая или тихая запись не отправляется на распознавание.
- Должна быть защита от слишком длинной записи по времени и размеру буфера.

## 9. Индикатор записи и распознавания

Вместо всплывающего окна записи используется нативная рамка по краям экрана:

- зелёная рамка означает активную запись;
- оранжевая рамка означает распознавание или вставку;
- ширина рамки: 12 пикселей;
- рамка скрывается после завершения, отмены или ошибки.

Старое всплывающее окно записи может оставаться в коде как legacy fallback, но в обычном сценарии не используется.

Windows toast-уведомления не используются.

## 10. Звуки

Приложение проигрывает короткие встроенные звуки:

- начало записи;
- остановка записи;
- ошибка.

Звуковое оповещение включается и выключается одним параметром в общих настройках. Отдельной вкладки `Звуки` и тестовых кнопок звуков нет.

## 11. Окно настроек

Окно настроек компактное, одноэкранное, без вкладок, боковой навигации, карточек, кнопок `Save` и `Close`. Все параметры сохраняются сразу после изменения.

Требования к UI:

- в заголовке окна используется иконка приложения;
- окно имеет фиксированный комфортный размер и не меняет масштаб при переносе между мониторами;
- разворачивание окна отключено;
- все параметры помещаются в окно без прокрутки;
- широкие параметры занимают целую строку;
- узкие параметры сгруппированы в две визуально разделённые колонки;
- названия параметров выровнены по центру относительно поля значения;
- выпадающие списки имеют белый фон и не должны обрезать выбранное значение;
- tooltip-подсказки работают для основных полей;
- строка состояния внизу оформлена как поле с границей, текст можно выделить, но нельзя редактировать.

Параметры в окне:

- клавиша транскрибации;
- активный профиль;
- Base URL;
- API key;
- модель;
- температура;
- таймаут API;
- режим записи;
- порог тишины;
- таймаут тишины;
- максимальная длительность записи;
- запуск вместе с Windows;
- звуковое оповещение;
- язык интерфейса;
- уровень логов;
- восстановление буфера обмена;
- задержка вставки;
- задержка восстановления буфера;
- кнопка открытия папки логов.

Неизменяемые информационные строки в настройках не отображаются.

## 12. Tray icon

Контекстное меню tray icon содержит только:

- `Settings` / `Настройки`;
- `Exit` / `Выход`.

Меню локализуется согласно выбранному языку интерфейса.

Левый клик по tray icon открывает окно настроек.

Иконка имеет состояния:

- idle;
- recording;
- transcribing;
- error, кратковременно.

## 13. Автозапуск

Автозапуск включается только через галочку в GUI.

Registry key:

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
```

Интерактивный установщик может предложить запустить приложение после установки, но не включает автозапуск сам.

## 14. Установка и удаление

Installer requirements:

- установка в `%APPDATA%\VoiceInsert`;
- имя приложения в winget/ARP: `VoiceInsert`;
- package id: `strokinkv.VoiceInsert`;
- создание Start Menu shortcut;
- интерактивная галочка запуска приложения после установки;
- тихая установка:

```powershell
VoiceInsertSetup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

- регистрация тихого удаления для `winget uninstall "VoiceInsert" --silent`;
- корректное обновление поверх предыдущей версии.

## 15. Настройки и секреты

Обычные настройки хранятся в:

```text
%APPDATA%\VoiceInsert\settings.json
```

API key нельзя хранить открытым текстом. Используется Windows DPAPI.

DPAPI - встроенный механизм Windows Data Protection API. Он шифрует секреты так, чтобы расшифровать их мог тот же Windows-пользователь на той же машине. Приложению не нужен отдельный мастер-пароль или собственное хранение ключей.

## 16. Логи и приватность

Логи пишутся в:

```text
%LOCALAPPDATA%\VoiceInsert\Logs
```

Файлы логов должны заканчиваться на `.log`.

В логи нельзя писать:

- распознанный текст;
- аудио;
- API key;
- полный request body;
- полный response body, если он может содержать пользовательский текст.

Можно писать:

- время события;
- состояние приложения;
- длительность записи;
- размер аудио;
- endpoint/base URL без секретов;
- HTTP status code;
- тип ошибки;
- stack trace;
- длительность API-запроса;
- факт успешной вставки без текста.

В настройках можно открыть папку логов и выбрать уровень логирования. Последний статус и последняя ошибка отдельными строками не отображаются; текущая ошибка показывается в строке состояния.

Приложение само отправляет данные только в endpoint, настроенный пользователем. При использовании `ai2npu` по умолчанию данные уходят на локальный API.

## 17. Локализация

GUI поддерживает:

- `Русский`;
- `English`.

Выбранный язык сохраняется и применяется к настройкам, tray menu, значениям режима записи и уровня логов.

## 18. Обработка ошибок

При ошибке приложение должно:

- проиграть error sound, если включено звуковое оповещение;
- скрыть рамку-индикатор, если она активна;
- записать технические детали в лог без пользовательского текста;
- вывести ошибку в строку состояния окна настроек;
- не вставлять неполный или ошибочный текст;
- вернуться в idle state.

Типовые ошибки:

- микрофон недоступен или занят;
- горячая клавиша не зарегистрирована;
- API key пустой для API, где он нужен;
- Base URL некорректный;
- API недоступен;
- timeout;
- HTTP error;
- ответ API не содержит `text`;
- clipboard недоступен;
- вставка не удалась.

## 19. Acceptance criteria

1. Приложение устанавливается на Windows 11 в `%APPDATA%\VoiceInsert`.
2. После запуска появляется tray icon.
3. Левый клик по tray icon открывает окно настроек.
4. Tray menu содержит `Settings` / `Настройки` и `Exit` / `Выход` и локализуется.
5. По умолчанию создаются профили `ai2npu` и `groq`.
6. `ai2npu` является первым активным профилем.
7. `ai2npu` указывает на `http://localhost:9555` и использует модель `openai/whisper-large-v3-turbo`.
8. `groq` указывает на `https://api.groq.com/openai/`, создаётся без API key и использует `whisper-large-v3`.
9. Можно создать, выбрать и удалить API профиль.
10. Загрузка моделей выполняется через `GET {base_url}/v1/models` выбранного профиля.
11. В GUI есть одно поле `Model` с выпадающим списком.
12. Транскрибация вызывает `POST {base_url}/v1/audio/transcriptions`.
13. API метод `translate` не вызывается.
14. `Ctrl+Space` запускает транскрибацию.
15. Работают режимы `Toggle`, `Hold`, `Hybrid` и `SilenceTimeout`.
16. В `Hybrid` и `SilenceTimeout` запись может завершаться по тишине.
17. Повторное нажатие горячей клавиши во время ожидания API отменяет транскрибацию.
18. Во время записи показывается зелёная рамка по краям экрана.
19. Во время транскрибации и вставки показывается оранжевая рамка.
20. Текст вставляется через clipboard в активное окно.
21. Аудио и распознанный текст не сохраняются на диск.
22. Логи не содержат аудио, распознанный текст и API key.
23. Раздел логов позволяет открыть папку логов и выбрать log level.
24. Ошибки выводятся в read-only строку состояния.
25. API key хранится через DPAPI отдельно для каждого профиля.
26. Установщик поддерживает тихую установку и тихое удаление.
27. В настройках есть tooltip для основных полей.
28. VoiceInsert всегда использует системный микрофон по умолчанию.
