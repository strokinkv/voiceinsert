# Журнал изменений

## 2.1.1 - 2026-07-23

### Исправлено

- Обновлены зависимости и `Cargo.lock`, чтобы `cargo audit` проходил без уязвимостей в CI.

## 2.1.0 - 2026-07-23

### Добавлено

- Добавлен гибридный режим записи: короткое нажатие работает как переключатель, отпускание после удержания дольше 2 секунд останавливает запись и запускает распознавание, а длинная пауза останавливает запись по тем же порогам, что и режим тишины.
- Добавлена отмена долгого распознавания и вставки: повторное нажатие горячей клавиши во время ожидания ответа API отменяет активную задачу распознавания и возвращает приложение в состояние ожидания.
- Добавлен захват и обработка одиночных горячих клавиш, включая улучшенную поддержку клавиши Windows Copilot/F23.
- Добавлена нативная рамка по краям экрана для состояний записи и распознавания вместо старого всплывающего окна записи поверх всех окон.
- Добавлено окно настроек с автосохранением: изменения сохраняются сразу после ввода, выбора значения, переключения параметра или смены профиля.
- Добавлен выбор из выпадающих списков для API профиля, модели, режима записи, языка интерфейса и уровня логов.
- Добавлена автоматическая загрузка списка моделей при запуске приложения, переключении активного профиля и сохранении профиля.
- Добавлена выделяемая read-only строка состояния в окне настроек для текущего статуса и текста ошибки.
- Добавлена иконка приложения для исполняемого файла и заголовка окна настроек.

### Изменено

- Интерфейс настроек переработан в компактное окно без вкладок и карточек: широкие параметры занимают всю строку, небольшие параметры сгруппированы в выровненные колонки.
- Кнопки `Save` и `Close` удалены из окна настроек, так как параметры теперь сохраняются сразу.
- Левый клик по иконке в трее теперь открывает окно настроек вместо контекстного меню.
- Ширина рамки-индикатора настроена на 12 пикселей.
- Звуки начала и остановки записи сделаны более мелодичными, громкость уведомлений и ошибок уменьшена.
- Переключение языка сделано единообразным: варианты режима записи, языка интерфейса и уровня логов теперь соответствуют выбранному языку интерфейса.
- Улучшены размер окна настроек и поведение при переносе между мониторами: окно больше не скачет и не меняет масштаб.

### Исправлено

- Исправлены выпадающие списки, которые показывали пустое значение после смены выбора.
- Исправлены ширина полей настроек и выравнивание правого края элементов.
- Исправлено кратковременное появление окна записи за пределами видимой области экрана.
- Исправлен сценарий Toggle/Copilot, где отпускание клавиши могло непреднамеренно остановить запись.
- Исправлено имя файлов логов: теперь они заканчиваются на `.log`.
- Исправлена обработка записей без речи: пустые и тихие записи не отправляются на распознавание и не вставляют текст-заглушку от API.
- Исправлены устаревшие фоновые события после отмены распознавания: отменённые задачи больше не переводят интерфейс в состояние ошибки или завершения.

### Удалено

- Удалён сценарий перевода русского текста на английский и прекращено использование API метода `translate`.
- Удалены неизменяемые строки настроек, такие как режим запуска и режим окна записи.
- Удалена вкладка `Звуки` и отдельные настройки звуковых событий; звуковое оповещение теперь настраивается одним параметром в общих настройках.
- Удалены ручные кнопки загрузки моделей и теста из API профилей; загрузка моделей выполняется автоматически.
- Удалены отображение последнего статуса, последней ошибки и очистка логов из области логов.

## Не выпущено

- Нет невыпущенных изменений.

## 2.0.0 - 2026-05-29

- Приложение заменено реализацией на Rust + Slint.
- Локальный API профиль по умолчанию изменён на `ai2npu` по адресу `http://localhost:9555`.
- Удалены устаревшие артефакты проекта и неактуальная документация от предыдущей реализации.

## 1.1.0

- Повышена надёжность жизненного цикла записи: устаревшие таймеры максимальной длительности больше не могут остановить новую сессию записи.
- Второй экземпляр VoiceInsert больше не продолжает запуск, если приложение уже работает.
- Добавлены интерфейсы зависимостей контроллеров и расширено покрытие unit-тестами для режимов переключателя, удержания, тайм-аута тишины, ошибок API, пустого аудио и вставки через буфер обмена.
- Добавлена проверка Base URL API и отдельная команда проверки состояния API профиля для окна настроек.
- API клиенты теперь используют заголовки авторизации на уровне запроса вместо изменения общих настроек клиента.
- Добавлена проверка и нормализация горячих клавиш, чтобы отклонять небезопасные или неизвестные сочетания и избегать дублирования горячих клавиш распознавания и перевода.
- Улучшено восстановление буфера обмена: сохраняется полный объект данных буфера, а не только Unicode-текст.
- Усилен CI: предупреждения считаются ошибками, добавлены проверки форматирования, аудит зависимостей, сбор покрытия и загрузка артефакта покрытия.
- Добавлен GitHub workflow для релизов с упакованными установщиками.
- Метаданные версии централизованы и передаются в сборку пакета Inno Setup.
- Добавлены ссылки метаданных установщика и разделы диагностики в английскую и русскую документацию.

## 1.0.0

- Первый выпуск приложения для Windows 11 с иконкой в трее.
- Глобальные горячие клавиши для распознавания речи и перевода речи на английский.
- API профили для OpenAI-совместимого аудио API.
- Вставка через буфер обмена с опциональным восстановлением прежнего содержимого.
- Окно записи с прокручивающейся формой амплитуды.
- Интерфейс настроек на русском и английском языках.
- API ключи профилей защищены через DPAPI.
- Установщик Inno Setup с поддержкой тихой установки и удаления.
